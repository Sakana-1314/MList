# MList

局域网文件管理系统：把服务器上的目录按用户授权，通过 **Web / WebDAV / S3 / SMB / REST API** 访问。

> 📖 **文档**：<https://sakana-1314.github.io/MList/> ・ **在线试用**：<https://sakana-1314.github.io/MList/demo> ・ **API 文档**：<https://sakana-1314.github.io/MList/api>

## 功能

- **文件管理**：浏览（列表 / 网格）、新建、重命名、移动、复制、删除、下载；拖放 / 多文件上传队列。
- **在线预览**：图片、视频、音频、PDF、文本 / 代码（可编辑）；视频支持多音轨与内嵌 / 外挂字幕。
- **实时转码串流**：浏览器无法直接播放的视频（MKV、HEVC、AVI…）实时转为 HLS，
  **分片按需生成，可随意拖动进度**；可选画质（原画 / 1080p / 720p / 480p）、码率与输出编码（默认 H.265，可选 H.264），支持硬件编码。
- **预览图与缓存治理**：自动生成多尺寸缩略图；预览图与转码分片分别设保留时长与容量上限（LRU 淘汰）；
  缓存以文件内容为标识，移动、重命名或更换挂载目录都不会让预览失效，相同内容共用缓存。
- **用户与权限**：管理员按目录授权并设置**只读 / 可读写**，所有协议共用同一套检查。
- **访问令牌**：带 `read` / `write` 范围与有效期的 API 令牌（`ml_` 前缀），可随时在设置中查看或吊销。
- **协议与挂载**：WebDAV（`/dav`）、S3 兼容接口（每个授权桶一个 bucket）、SMB（托管 Samba）。
- **模糊搜索**：常驻内存的文件名索引，fzf 风格子序列匹配打分，只返回当前用户有权访问的文件。
- 深色模式，桌面与移动端自适应。

## 快速开始

镜像已发布在 GitHub Container Registry（公开，无需登录即可拉取），支持 linux/amd64 与 linux/arm64：

```bash
docker pull ghcr.io/sakana-1314/mlist:latest

docker run -d --name mlist \
  -p 8080:8080 -p 9000:9000 -p 445:445 \
  -v mlist-data:/data \
  -v /srv/media:/media \
  ghcr.io/sakana-1314/mlist:latest
```

镜像名必须**全小写**。

- `8080` Web / REST API / WebDAV，`9000` S3，`445` SMB；数据保存在 `/data`，**请持久化并纳入备份**。
- 容器默认以 root 运行（`smbd` 监听 445、自动创建 SMB 系统账户都需要 root）；不用 SMB 时可用普通用户运行。

## 使用

1. 浏览器打开 `http://<服务器IP>:8080`，用默认账户 `admin` / `admin123` 登录。
2. **立即在右上角「账号设置」修改密码**。
3. 在「系统管理」创建桶（对应服务器目录，可指定多个目录互为备份）。
4. 在「用户管理」创建用户并授权桶——**管理员自己也需要授权桶才能看到文件**。
5. 打开「挂载」页面，复制按你的服务器与账号生成好的 WebDAV / S3 / SMB 连接命令。

更多用法见[文档](https://sakana-1314.github.io/MList/)：功能详解、挂载方式、配置项、部署与开发。
